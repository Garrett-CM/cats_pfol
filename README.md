# Cats Paws of Furry, Original Litter

> Think *Binding of Isaac* but done poorly by someone trying out game dev.

A ROUGH 2D roguelite where you play as a snot spitting cat clearing rooms of angry cucumbers, vacuum cleaners, and bad luck.

---

## Requirements

* **Python:** `3.10+` recommended (must be Python 3)
* **Pygame:** `pygame-ce` or standard `pygame` (v2.0+)

---
